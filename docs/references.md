# Engineering references

The repository contains original demo code and synthetic data. These external sources informed the implementation; no third-party sample application code or production datasets were copied.

- [FastAPI tutorial](https://fastapi.tiangolo.com/tutorial/) — application structure and local execution.
- [FastAPI testing](https://fastapi.tiangolo.com/tutorial/testing/) — TestClient and pytest testing pattern.
- [GitHub Actions workflow syntax](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax) — workflow and job structure.
- [Google SRE incident management guide](https://sre.google/resources/practices-and-processes/incident-management-guide/) — incident roles, preparation, response, and blameless learning.
